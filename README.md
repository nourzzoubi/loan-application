## ✨ Overview

**Loan Application** is a modern single-page loan application interface designed to provide users with a clean, intuitive, and professional experience when submitting loan information.

The project focuses on building a polished fintech-style interface while applying modern React development practices, responsive design, and Tailwind CSS utility classes.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nourzzoubi/loan-application.git
```

### 2. Navigate to the project

```bash
cd loan-application
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## 🚀 Deployment

The project is deployed using **GitHub Pages**.

To deploy a new production version:

```bash
npm run deploy
```

The deployment builds the application and publishes the `dist` directory to the `gh-pages` branch.
